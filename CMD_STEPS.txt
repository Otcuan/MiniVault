MINI VAULT - WINDOWS CMD

1.  cd /d D:\MiniVault
2.  py -m venv .venv
3.  .venv\Scripts\activate.bat
4.  python -m pip install -r requirements.txt
5.  python -m pytest -q
6.  python -m uvicorn main:app --reload
7.  Open http://127.0.0.1:8000/docs
8.  Regenerate submission evidence: python -m scripts.generate_samples
9.  Before a clean demo: reset_runtime_data_cmd.bat
10. Optional config: copy .env.example to .env and edit

NOTE: if the server refuses to start with "database was created by an older
Mini Vault schema", run reset_runtime_data_cmd.bat. The schema changed when KV
versioning and Transit key rotation were added.
